# Fedplay

Reprodutor de áudio leve e elegante para Fedora Linux, com foco em gestão de metadados.

![License](https://img.shields.io/badge/license-GPLv3-blue.svg)
![Rust](https://img.shields.io/badge/rust-1.70%2B-orange.svg)
![GTK4](https://img.shields.io/badge/GTK-4.10%2B-green.svg)

## Características

- 🎵 Reprodução de MP3 e M4A (AAC)
- 🏷️ Edição robusta de metadados (ID3, MP4)
- 🎨 Interface moderna com Libadwaita
- ⚡ Leve e rápido (<50MB RAM)
- 🔌 Integração nativa com GNOME (MPRIS2)
- 🌙 Modo escuro/claro automático

## Instalação

### Fedora (RPM)

```bash
sudo dnf copr enable seu_usuario/fedplay
sudo dnf install fedplay
```
